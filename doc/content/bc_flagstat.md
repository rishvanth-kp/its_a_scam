# bc_flagstat

## Description
`samtools flagstat` is extremely useful to get alignment statistics
such as the number of aligned reads, number of PCR duplicates, etc. from
a SAM/BAM file. `bc_flagstat` is used to give almost the same information as
`flagstat` at a single cell level.

## Parameters
```
bc_flagstat [options]
  -a aligned SAM/BAM file [required]
  -b barcode list [required]
  -o outfile prefix [required]
  -d name split delimiter [default: ":"; ignored if -t is provided]
  -c barcode field in name [default: 7 (0 based); ignored if -t is provided]
  -t barcode tag in SAM file [default: ""]
  -q minimum mapping quality to include [default: 0]
  -v verbose [default: false]
```

`-a`: The input aligned SAM or BAM file. Each alignment is counted
separately. The cell barcode should be present either in a SAM tag or
encoded in the query name (QNAME) field, see options `-t`, `-d`, and
`-c`. [Required].

`-b`: Only the alignments with a barcode in this file are counted.
[Required].

`-o`: Output file prefix. [Required].

`-d`: Used when the cell barcode is encoded as a part of the query name
(QNAME field). Split the QNAME by the specified delimiter. [Default:
":"].

`-c`: Used when the cell barcode is encoded as a part of the query name
(QNAME field). Split the QNAME by the delimiter specified by `-d`
and take the barcode as the value in the column specified by `-c` (0
based). For example, reads that are generated by Illumina sequencers
have FASTQ names with 7 fields that are separated by a ":", and
the cell barcode is typically added as the 8th field. The column must
exist in the QNAME of every alignment; this is not checked. [Default: 7].

`-t`: Used when the cell barcode is present in a SAM entry as a tag. For
example, SAM files generated by CellRanger encode the error-corrected
cell barcode in the `CB` tag. If this parameter is set, `-d` and `-c`
flags are ignored. [Default: none].

`-q`: Include only alignments with a mapping quality greater than or
equal to the specified value. Unmapped reads usually have a mapping
quality of 0, and are therefore not counted if this value is larger
than 0. [Default: 0].

`-v`: Verbosity flag. Set the flag to print progress and statistics to
standard error. [Default: false].

## Input and output file description
### Description of input files
1. An aligned SAM/BAM file that has a cell barcode encoded
either in the query name or in a tag.
2. An uncompressed TSV file with the cell barcode in the first column.
Only the alignments containing barcodes in the file are counted.

### Description of output files
`<output_prefix>_bc_flagstat.txt`: A file containing the single cell
flagstats. Each row of the file corresponds to a cell, in the same order
as the barcode list. The first column contains the cell barcode, and the
flagstats start from the second column. The following counts are
computed for each cell: primary, secondary, supplementary, duplicates,
primary_duplicates, mapped, primary_mapped, paired_in_sequencing,
read_1, read_2, properly_paired, with_itself_and_mate_mapped, and
singletons. Each alignment is counted separately. The definitions of
these are similar to `samtools flagstat` as defined
[here](https://www.htslib.org/doc/samtools-flagstat.html), with the
following differences:

- The counts from paired_in_sequencing to singletons include all the
  alignments, including the secondary and supplementary alignments
  (`samtools flagstat` counts only the primary alignments).
- QC-failed alignments (flag 0x200) are not counted separately.
- Alignments with a mapping quality lower than `-q` are not counted.
- The total number of alignments is not reported.

This file contains a header line.
