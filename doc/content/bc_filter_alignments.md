# bc_filter_alignments

## Description
An aligned SAM/BAM file contains reads from all cell barcodes. However,
most cell barcodes would contain too few reads to be useful for
downstream analysis. This program is used to retain alignments that
belong to a set of desired cell barcodes.

## Parameters
```
bc_filter_alignments [options]
	-a aligned SAM/BAM file [required]
	-b barcode list file [required]
	-o out file name [required]
	-d name split delimiter [default: ":"]; ignored if -t is provided
	-c barcode field in name [default: 7 (0 based); ignored if -t is provided]
	-t barcode tag in SAM file [default ""]
	-q minimum mapping quality to include [default: 0]
	-f only include if all the flags are present [default: 3]
	-F only include if none of the flags are present [default: 3340]
	-v verbose [default: false]
```

`-a`: The input aligned SAM or BAM file. The cell barcode
should be present either in a SAM tag or encoded in the query name
(QNAME) field, see options `-t`, `-d`, and `-c`. With the default `-f`,
only paired reads are included; for single-end data, use `-f 0`.
[Required].

`-b`: A list of barcodes to retain in the output file. [Required].

`-o`: Output file name. [Required].

`-d`: Used when the cell barcode is encoded as a part of the query name
(QNAME field). Split the QNAME by the specified delimiter. [Default:
":"].

`-c`: Used when the cell barcode is encoded as a part of the query name
(QNAME field). Split the QNAME by the delimiter specified by `-d`
and take the barcode as the value in the column specified by `-c` (0
based). For example, reads that are generated by Illumina sequencers
have FASTQ names with 7 fields that are separated by a ":", and
the cell barcode is typically added as the 8th field. The column must
exist in the QNAME of every alignment; this is not checked. [Default: 7].

`-t`: Used when the cell barcode is present in a SAM entry as a tag. For
example, SAM files generated by CellRanger encode the error-corrected
cell barcode in the `CB` tag. If this parameter is set, `-d` and `-c`
flags are ignored. [Default: none].

`-q`: Include only alignments with a mapping quality greater than or
equal to the specified value. [Default: 0].

`-f`: Include only alignments that have all of the specified flags
present. For example, to include paired reads (0x1, decimal 1) and reads
that are mapped in proper pair (0x2, decimal 2), specify the sum of
these flags (1 + 2 = 3). [Default: 3].

`-F`: Include only alignments that have none of the specified flags
present. For example, to exclude PCR duplicates (0x400, decimal 1024) and
supplementary alignments (0x800, decimal 2048), specify the sum of these
flags (1024 + 2048 = 3072). The default (4 + 8 + 256 + 1024 + 2048 =
3340) excludes alignments that are unmapped (0x4), have an unmapped mate
(0x8), are secondary alignments (0x100), are PCR duplicates (0x400), or
are supplementary alignments (0x800). [Default: 3340].

`-v`: Verbosity flag. Set the flag to print progress and statistics to
standard error. [Default: false].

## Input and output file description
### Description of input files
1. An aligned SAM/BAM file that has a cell barcode encoded
either in the query name or in a tag.
2. An uncompressed TSV file with the cell barcode in the first column
(for example, the output of [`barcode_count`](barcode_count.md)). Only the
alignments containing barcodes in the file are retained in the output
SAM file.

### Description of output files
A SAM file with just the alignments whose cell barcodes are contained in
the provided barcode list. The `-q`, `-f`, and `-F` filters are applied
to each alignment independently, so for paired-end data, a read can be
included in the output without its mate. Of note, the output is always
in SAM format at the moment, and will be upgraded to generate either SAM
or BAM files in the future.
