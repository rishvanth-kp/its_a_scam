# nametag_to_samtag


## Description
Mappers designed for whole-genome samples typically do not have an
option to keep track of a cell barcode. This can be overcome by appending
the cell barcode to the name of each read in the fastq file (see
[`add_barcode_to_fastq_name`](add_barcode_to_fastq_name.md)).  Thus, the
`QNAME` field of the aligned SAM file contains the cell barcode. However,
many downstream tools require the cell barcode in a separate SAM
tag. This program parses the QNAME to extract the cell barcode and
creates a SAM tag for it.

## Parameters
```
nametag_to_samtag [options]
  -a aligned SAM/BAM file [required]
  -o out SAM file [required]
  -d name split delimiter [default: ":"]
  -c barcode field in name [default: 7]
  -t SAM tag to add barcode to [default: CB]
  -z SAM tag type [default: Z]
  -s suffix to add to output barcode [default: ""]
```

`-a`: The input aligned SAM or BAM file. The cell barcode
should be encoded in the query name (QNAME) field, see options `-d` and
`-c`. [Required].

`-o`: Output SAM file name. [Required].

`-d`: Used when the cell barcode is encoded as a part of the query name
(QNAME field). Split the QNAME by the specified delimiter. [Default:
":"].

`-c`: Split the QNAME by the delimiter specified by `-d` and take the
barcode as the value in the column specified by `-c` (0 based). For
example, reads that are generated by Illumina sequencers have FASTQ
names with 7 fields that are separated by a ":", and the cell
barcode is typically added as the 8th field. The column must exist in
the QNAME of every alignment; this is not checked. [Default: 7].

`-t`: The name of the SAM tag to put the cell barcode in. Has to be a
two-character string according to the SAM specification. [Default: CB].

`-z`: The type of the SAM tag. `Z` indicates a printable string, and
is the appropriate type for a cell barcode string. [Default: Z].

`-s`: Suffix to add to the end of the barcode. This parameter is
useful to make the barcode format consistent with tools that suffix the
barcodes with a `-1`. [Default: none].

## Input and output file description
### Description of input files
A SAM/BAM file that has a cell barcode encoded in QNAME. The input
can be a single- or paired-end aligned file. The alignments should
not already contain the tag specified by `-t`; the new tag is added
without checking for an existing one.

### Description of output files
A SAM file with an additional tag that contains the cell barcode.
The QNAME is not changed, i.e., it still contains the cell barcode.
Of note, the output is a SAM file at the moment, and will
be upgraded to output both SAM and BAM files in the future.
