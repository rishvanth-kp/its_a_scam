# bc_mismatch_matrix


## Description
`bc_mismatch_matrix` finds the bases that differ from the reference
genome in each cell, and compares the cells by the mismatches that they
share. For each cell, the read bases that do not match the reference are
found from the CIGAR string and the MD tag of each alignment; insertions
and deletions are not considered. At each position, the cell is assigned
the most frequent mismatched base, if the depth (`-d`) and the variant
allele frequency (VAF, `-l`) of that base are high enough. The cells are
then compared pairwise with the Jaccard index of their mismatched bases.

## Parameters
```
bc_mismatch_matrix [options]
	-a aligned SAM/BAM file [required]
	-b barcode file [required]
	-o out file prefix [required]
	-d minimum depth at base to consider [default: 1]
	-l minimum VAF at base to consider [default: 0]
	-t cell barcode tag [default: CB]
	-q minimum mapping quality to include [default: 0]
	-f only include if all of the flags are present [default: 0]
	-F only include if none of the flags are present [default: 2052]
	-v verbose [default: false]
```

`-a`: The input aligned SAM or BAM file. The cell barcode should be
present in a SAM tag (see option `-t`), and the alignments should have
an MD tag (see below). [Required].

`-b`: Only the alignments that match a barcode in this file are
processed. [Required].

`-o`: Output file prefix. [Required].

`-d`: Minimum depth of a cell at a position to call a base. The depth is
the number of alignments of the cell that have a base aligned to the
position, including the alignments that match the reference.
[Default: 1].

`-l`: Minimum VAF of a cell at a position to call a base, between 0 and
1. The VAF is the number of alignments of the cell that have the most
frequent mismatched base at the position, divided by the depth. If two
bases are equally frequent, the first of A, T, G, and C is used. `N`
bases are not counted as a base; if the reads contain `N`, set `-l`
greater than 0. [Default: 0].

`-t`: The SAM tag that contains the cell barcode. For example, SAM files
generated by CellRanger encode the error-corrected cell barcode in the
`CB` tag. [Default: CB].

`-q`: Include only alignments that have a mapping quality greater than
or equal to the specified value. [Default: 0].

`-f`: Include only alignments that have all of the specified flags
present. For example, to include paired reads (0x1, decimal 1) and reads
that are mapped in proper pair (0x2, decimal 2), specify the sum of these
flags (1 + 2 = 3). [Default: 0].

`-F`: Include only alignments that have none of the specified flags
present. For example, to exclude PCR duplicates (0x400, decimal 1024)
and supplementary alignments (0x800, decimal 2048), specify the sum of
these flags (1024 + 2048 = 3072). The default (4 + 2048 = 2052) excludes
unmapped (0x4) and supplementary (0x800) alignments; PCR duplicates
(0x400) and secondary alignments (0x100) are included unless they are
added to this value. [Default: 2052].

`-v`: Verbosity flag. Set the flag to print progress, and the number of
alignments included for each cell, to standard error. [Default: false].

## Input and output file description
### Description of input files
1. A single- or paired-end aligned SAM/BAM file that has the cell
barcode in a tag. Each alignment is processed separately, so if the two
reads of a fragment overlap, the overlapping bases are counted twice.
Base qualities are not considered. The file must meet these
requirements:
    - The alignments must be grouped by cell barcode, i.e., all the
      alignments of a cell must be consecutive in the file (for example,
      after `samtools sort -t CB`); this is not checked. Alignments that
      are not in the barcode list, or that are filtered out, can be
      between them. If the alignments of a cell are split into several
      groups, the cell is counted more than once.
    - The included alignments must have an MD tag, which can be added
      with `samtools calmd`. The program stops with an error if an
      alignment does not have one.
    - At least one alignment must have a barcode in the barcode list;
      this is not checked.
2. An uncompressed TSV file with the cell barcodes in the first column
(for example, the output of [`barcode_count`](barcode_count.md)). The
barcodes must be unique; this is not checked.

### Description of output files
The cells are in the same order as the barcode list in both files.

1. `<output_prefix>_mm_matrix.txt`: A tab-separated matrix with a header
line. The first three columns are the chromosome, start, and end of each
region (0-based start, and the end is not included), and the subsequent
columns are the cells. Each value is the base called for the cell at the
region, or `.` if no base is called (i.e., the cell has no coverage, no
mismatch, or does not pass `-d` or `-l`). Only the positions at which at
least one cell has a call are included, and adjacent positions that have
the same calls in all the cells are merged into a single region.
2. `<output_prefix>_jaccard.txt`: A cell-by-cell matrix of Jaccard
indices. For a pair of cells, the Jaccard index is the number of bases at
which both cells have the same call, divided by the number of bases at
which either cell has a call. The first line contains the cell barcodes
(without a field for the first column), and the first column of the
other lines contains the cell barcode. The diagonal is 1, or 0 for a cell
that has no calls.
